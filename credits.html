About this website

Made to share Syria's stories

This four-page website was built as a front-end development student project using HTML, CSS, and a little JavaScript. The pages introduce Syria's history, cultural traditions, places, and food.

The eagle logo is the original vector artwork provided for this project. The favicon uses the same eagle design.
