# Discover Syria

A responsive four-page student website exploring Syria's history, culture, places, food, and traditions.

## Pages

- `index.html` — homepage and local MP4 video
- `heritage.html` — heritage, culture, and audio
- `journey.html` — destinations, food, and facts
- `credits.html` — project credits and demo feedback form

## Project files

- `css/normalize.css` — consistent browser defaults
- `css/style.css` — layout, colors, and responsive styles
- `js/feedback.js` — on-page feedback form behavior
- `images/` — images, logo, and favicons
- `media/` — local video and audio files

## Viewing the site

Open `index.html` in a browser or serve the project folder from a local development server. Links between the four HTML pages are relative so they work together when hosted in the same directory.

The feedback form is a class demonstration; it displays feedback on the page and does **not** send it to a server.

## Publishing

Uploading changes to GitHub does not by itself update the live GreenGeeks website. Upload the website files to the domain's document root separately unless automated deployment has been configured.
